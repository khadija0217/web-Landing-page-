# Landing Page

A modern and responsive landing page built using HTML and CSS based on a Figma design.

## Overview

This project is a frontend implementation of a landing page design created in Figma. The focus was on converting the design into a clean, responsive, and user-friendly web page.

## Features

- Responsive design
- Clean and modern user interface
- Semantic HTML structure
- Custom CSS styling

## Technologies Used

- HTML5
- CSS3
